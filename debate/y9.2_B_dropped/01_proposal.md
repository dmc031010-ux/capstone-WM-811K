# 01. 제안 — y9.2: die 수 줄인 실제 Scratch 를 fine-tune 라벨에 추가 (B 제한판) — Claude (2026-11-23)

## 배경 (y9.1 에서 확인한 것, 모두 val · seed 0)
- 레이어별 probe (`runs/y9.1_layer_probe`): Scratch 정보는 layer3 까지 늘어남 (vs none AUC 0.97~0.98). die 적은 웨이퍼는 stem 에서 크게 낮지만 (0.74 vs 0.94) layer4 에서 거의 따라잡음. 가장 큰 손실은 layer4 특징 → 모델 최종 출력.
- 판정층 바꾸기 (`runs/y9.1_head_probe`): 같은 train 라벨 (Scratch 48장) 로 헤드를 바꿔도 Scratch F1 ±0.04. balanced / 프로토타입은 재현↑ 대신 none→Scratch 오탐↑ (임계값 이동).
- → 가설: 병목은 인코더나 헤드 설계가 아니라 **Scratch 라벨 예시의 다양성 부족**.
- 사용자 조건: 선을 직접 그리는 합성 데이터는 쓰지 않음. 실제 웨이퍼 변형만.
- 미리보기 (`runs/y9.2_aug_preview/fig_B.png`): 2×2 묶음은 선이 뚜렷한 웨이퍼에서 선을 유지. 3×3 이나 배경 불량이 많은 웨이퍼는 배경이 부풀어 Random 처럼 됨 → 제한판.

## 제안
train 라벨 Scratch 중 조건을 만족하는 웨이퍼를 원본 die 격자에서 **2×2 칸씩 묶어** (칸 안에 불량이 하나라도 있으면 불량, 웨이퍼 die 가 하나라도 있으면 웨이퍼) die 수를 약 1/4 로 줄인 사본을 만들고, 96×96 으로 늘려 **Scratch 라벨로 fine-tune 라벨 풀에 추가**한다.

### 대상 웨이퍼 (seed 별 train 라벨에서만)
- 원본 격자 ≤ 96, die ≥ 1200 (묶은 뒤 약 300 이상): seed 0 18장, seed 1 17장 / 전체 Scratch 48장
- 배경 불량이 적을 것: 가장 큰 불량 연결 덩어리 (8-이웃) 를 뺀 나머지 불량 die 가 전체 die 의 3% 이하. 기준값은 실행 전 대상 장수와 그림으로 확인 후 고정 (val 을 보고 고르지 않음)
- 웨이퍼마다 사본 1장 (오프셋 (0,0)). 회전은 기존 fine-tune weak 증강이 매 스텝 적용

### 학습에서의 비중
- 기존 BalancedSampler 는 클래스 단위로 균형 → Scratch 가 배치에서 차지하는 비율 (1/9) 은 **그대로**. 추가 사본은 Scratch 클래스 안에서 원본과 같은 확률로 뽑힘 (Scratch 뽑기 중 약 25%).
- 즉 오버샘플링 (Scratch 비중↑) 이 아니라 **Scratch 안의 다양성만 늘림** → 임계값 이동 효과를 최소화하려는 설계.

### 실행 조건
- 인코더: 기존 y9 사전학습 인코더 (`masklat9_e50.pt`, seed 0·1 모두 있음) 를 그대로 사용 → **사전학습 없음, fine-tune 만** (3×30 epoch, seed 당 약 15~20분).
- 그 밖에 y9 와 동일 (라벨 6,919장, v3_nopl, 같은 sampler·lr·epoch). 비교 기준은 이미 있는 y9 seed 0·1 결과.

## 평가 (val 로 판단, test 는 마지막 보고만)
1. val macro, 소수 5개 F1, Scratch F1·재현·정밀, none→Scratch 오탐 수
2. val Scratch 를 die 수 <1200 / ≥1200 로 나눈 재현율 (가설의 핵심: die 적은 쪽이 올라야 함)
3. y9.1 노이즈 진단 (0~16%) 과 레이어 probe 를 같은 방식으로
- 진행 기준: seed 0·1 **둘 다** y9 대비 val macro 가 높고, 소수 5개 중 0.03 넘게 떨어진 클래스 없고, die<1200 Scratch 재현율이 오르며, none→Scratch 오탐이 y9 의 1.5배를 넘지 않을 것

## 예상 위험
- 대상이 seed 당 17~18장뿐이라 효과가 작을 수 있음. 게다가 train Scratch 48장 중 29장은 **이미 die < 1200** (516~1138). 즉 die 적은 예시가 아예 없던 것은 아님 → 효과가 없으면 "die 적은 예시 수" 가 병목이 아니라는 증거가 됨.
- 2×2 묶음 사본은 die 약 300~1900 이 되어, val die 적은 Scratch (중앙값 1139, 하위 25% 758) 와 분포가 일부만 겹침.
- 묶음 규칙이 선을 약간 두껍게 하거나 배경 불량을 약 4배 밀도로 만듦 (불량 칸이 커짐). 배경 3% 제한으로 줄이지만 0 은 아님.
- seed 2개로도 fine-tune 변동을 다 잡기 어려움 (y9 seed 간 val macro 차 0.024).

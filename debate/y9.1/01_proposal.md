# 01. y9.1 — 마스킹 대신 노이즈 증강으로 자기지도 사전학습 (교수님 제안) — Claude

## 교수님 제안 (9차 미팅 전)
- 바둑판 마스킹으로 지우는 대신, 가우시안 노이즈나 랜덤 불량을 **추가** 한 뷰와 원본을 맞추게 한다.
- Scratch 가 지워지지 않고 남으니 최소한 Scratch 는 잘 잡을 것. 노이즈 정도로 증강 강도를 조절할 수 있음. "밸리드한 방법".

## 내 평가: 해볼 가치가 높다. 단, 기대 근거는 교수님 설명과 조금 다르다.
- **교수님 근거 ("마스킹이 선을 지워서 Scratch 가 약하다") 는 우리 검증과 맞지 않는다.** runs/hough_eda/verify_mask.txt: 6px 마스킹은 선의 50% 를 가리고 5조각으로 끊지만, ver8 인코더의 선 민감도 (선 지움 / 다른 불량 지움 = 0.61) 는 마스킹 없는 SimCLR (0.61) 과 같았고, 가리는 양과도 비례하지 않았다.
- **대신 더 강한 근거가 있다: 랜덤 불량 노이즈에 불변하도록 배우는 것 = 우리가 찾은 오답 원인을 직접 겨냥.**
  - Scratch 를 none 으로 놓친 웨이퍼는 배경 불량 밀도가 높다 (맞힘 중앙값 0.078 vs 틀림 0.107, AUC 0.35/0.33, runs/ver8_eda/numbers.txt).
  - die 수 적은 웨이퍼 조작 실험에서 배경 잡음이 있으면 none, 깨끗하면 Loc 으로 감 (runs/hough_eda/fewdie_test.txt).
  - 실제 none 웨이퍼에도 흩어진 랜덤 불량이 많다. "흩어진 불량은 무시하고 구조(선·덩어리·링)를 본다" 는 표현이 바로 필요한 것.
- **위험**
  - R1. Random 클래스 (흩어진 불량이 많은 것이 정의) 와 none / Near-full 구분은 불량 밀도에 의존한다. 랜덤 불량에 불변하게 만들면 이 정보가 약해질 수 있다 → 노이즈 강도를 낮게, Random F1 하한 (0.717) 확인.
  - R2. 노이즈만으로는 과제가 너무 쉬워 붕괴할 수 있다 (ver6 의 20% 블록 마스킹: 12 스텝 만에 손실 0.06, z_std 0.02 부분 붕괴). → z_std 감시, 강도 범위를 넓게.
  - R3. 가우시안 노이즈는 {0, 0.5, 1} 세 값뿐인 지도에 현실에 없는 값을 만든다 (입력 분포 이동). **랜덤 불량 추가 (정상 die → 불량) 가 더 현실적**. 그리고 96×96 픽셀 단위로 넣으면 1픽셀 점이 되는데 실제 불량은 die 블록 (중앙값 약 3×3 픽셀) 이다 → **die 단위로 넣어야** 한다.

## 설계 (y9 = ver7 사전학습에서 뷰 생성만 바꿈)
- 기존 (ver6.py `_views`): 원본 (회전) 과 마스킹본 4장 (각자 회전 → 6px 바둑판 50%).
- y9.1: 원본 (회전) 과 **노이즈본 4장** (각자 회전 → die 단위 랜덤 불량 추가). 손실·EMA·predictor·나머지는 동일.
  - 랜덤 불량: 웨이퍼 안의 정상 die 를 확률 p 로 불량으로 바꿈. die 격자 (h, w) 는 wm811k_shapes_dies.npy 에서 읽어 96 픽셀 블록에 맞춤 (h, w ≤ 96 인 99.4%; 나머지는 픽셀 단위).
  - **강도: 뷰 4장에 서로 다른 p = 2%, 4%, 8%, 16%** (교수님 "강도 다르게"). 한 번의 사전학습에서 여러 강도를 함께 봄.
  - (선택) 정상화 노이즈: 불량 die 를 작은 확률로 정상으로 — 이번에는 넣지 않음 (Scratch 를 끊는 효과가 생겨 질문이 섞임).
- 가우시안 노이즈 버전은 R3 때문에 1차에서 제외 (원하면 y9.2 로).

## 평가 (사전 고정)
- 1차 판단 = seed 0 fine-tune **val macro** 를 y9 seed 0 (0.818) 과 비교. 소수 클래스 하한 (Near-full 0.837, Donut 0.802, Random 0.717, Scratch 0.435, Loc 0.631) 은 test 보고 시 표시.
- 보조 (학습 직후, 싸게): z_std 추이, 고정 특징 kNN / 선형 분류 (verify_mask.py [C] 와 같은 방식), 선 민감도 ([B]), die 수 적은 웨이퍼 조작 실험 (fewdie_test.py) 재사용.
- seed 0 에서 val 이 y9 보다 높으면 seed 1 반복.
- 비용: 사전학습 50 epoch 약 3.6시간 + fine-tune 약 30분 = seed 당 약 4시간. 코드 변경: augment.py 에 die 단위 랜덤 불량 함수, ver6.py `_views` 에 노이즈 모드, wafixmatch.py 에 y9.1 등록 (약 40줄).

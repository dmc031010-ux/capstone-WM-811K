# y9.1 — 마스킹 대신 노이즈 증강 자기지도학습 (파일럿)

## 1. 왜 했나

**문제: Scratch 가 가장 약함**
- 목표: WaFixMatch 재현값 (test macro 0.795) 을 넘고, 소수 5개 클래스가 재현값보다 0.03 넘게 떨어지지 않을 것
- y9 (= ver8) 은 seed 0 에서 0.831 로 통과, seed 1 에서 0.783 (Donut 0.729) 으로 미달
- Scratch F1 이 약 0.45 로 가장 낮음

**지금까지 분석에서 확인한 것**
- 놓친 Scratch 는 대부분 none / Loc 으로 감. 특징 공간에서도 none·Loc 사이에 섞여 있음
- die 수가 적은 웨이퍼는 96×96 으로 늘릴 때 선이 두꺼워져 Scratch 로 덜 보임 (합성선: 1 die 두께 0.90 → 2 die 두께 0.11)
- "격자 마스킹이 얇은 선을 지운다" 가설은 검증 결과 지지되지 않음

**교수님 제안**
- 마스킹 대신, 랜덤 불량을 뿌린 웨이퍼를 원본과 같은 표현으로 맞추도록 사전학습
- 기대: 모델이 "흩어진 점은 패턴이 아니고, 이어진 선이 패턴" 을 배움

**0단계: 학습 없이 약점부터 확인**
실제 val Scratch 웨이퍼에 die 단위 랜덤 불량을 추가했을 때 Scratch 판정 비율

| 모델 | 0% | 2% | 4% | 8% | 16% |
|---|---|---|---|---|---|
| y9 seed 0 | .43 | .31 | .23 | .04 | .00 |
| y9 seed 1 | .50 | .42 | .26 | .10 | .00 |
| SimCLR | .53 | .46 | .27 | .08 | .01 |

- 정상 die 의 8% 만 불량으로 바꿔도 Scratch 판정이 거의 사라짐
- none 웨이퍼는 16% 를 넣어도 none 유지
- → 지금 모델은 배경에 흩어진 불량이 조금만 섞여도 선을 놓침. 교수님 방법을 시험할 근거

**가설**: 같은 선을 두고 흩어진 불량을 늘릴 때, 노이즈로 사전학습한 모델이 y9 보다 Scratch 판정이 덜 흔들리는가

## 2. 설계

**노이즈 방식**
- 정상 die 만 불량으로 바꿈 (불량→정상 방향은 없음, 선은 그대로 남음)
- 픽셀이 아니라 die 단위 (실제 불량이 die 단위로 생기므로)
- 회전 전에 원래 die 격자에서 넣음 (회전 후에는 die 경계를 맞출 수 없음)
- 뷰 4장에 각각 2 / 4 / 8 / 16% (0단계에서 판정이 무너지던 구간). 타깃 뷰는 깨끗한 원본

**4가지 조건: 바뀌는 요소를 하나씩 분리**

| 조건 | 바꾼 것 | 알고 싶은 것 |
|---|---|---|
| ① 마스킹 | 없음 (y9 방식) | 기준선 |
| ② 마스킹 + projector | projector 추가 | projector 효과 |
| ③ 회전만 + projector | 마스킹 제거 | 마스킹을 뺀 효과 |
| ④ 노이즈 + projector | 랜덤 불량 추가 | 노이즈를 더한 효과 (교수님 제안) |

- 참고선: SimCLR (ver3). 증강에 이미 픽셀 단위 노이즈 (5%, 양방향) 가 있음

**실행·평가**
- seed 0, 사전학습 10 epoch (조건마다 같은 예산), fine-tune 3×30 epoch
- 판단은 val 만: 고정 인코더 선형 probe, fine-tune 후 성능, 노이즈 곡선

## 3. 결과 (val)

| 조건 | 고정 인코더 선형 macro | FT macro | FT Scratch | 8% 노이즈 시 Scratch 판정 |
|---|---|---|---|---|
| ① 마스킹 | 0.534 | 0.803 | 0.470 | 0.11 |
| ② 마스킹 + projector | 0.527 | 0.794 | 0.337 | 0.05 |
| ③ 회전만 + projector | 0.594 | **0.815** | **0.524** | 0.16 |
| ④ 노이즈 + projector | **0.677** | 0.803 | 0.467 | 0.19 |
| 참고 y9 (50 epoch) | 0.566 | 0.818 | 0.446 | 0.04 |
| 참고 SimCLR (50 epoch) | 0.732 | 0.820 | 0.553 | 0.08 |

## 4. 해석
- **마스킹을 빼면 좋아짐 (② → ③)**: 특징 유효 랭크 34.9 → 103.8, fine-tune 결과 최고
- **노이즈는 표현을 좋게 했지만 fine-tune 이득으로는 안 이어짐 (③ → ④)**: 고정 인코더 점수 최고 (SimCLR 에 가장 근접). fine-tune 후엔 Scratch 를 none 으로 더 많이 보냄 (val Scratch 119장 중 none 오분류 39 → 60)
- **projector 만 붙이면 나빠짐 (① → ②)**: 출력 차원도 512 → 128 로 함께 바뀌어 projector 만의 효과라고 단정 불가
- **10 epoch 로는 어느 조건도 y9 50 epoch (0.818) 를 못 넘음**: ③ 도 y9 대비 Donut −0.060, Near-full −0.043 으로 클래스별 기준 미달

## 5. 한계와 다음 단계

**한계**
- seed 1개, 사전학습 10 epoch. 학습률이 총 epoch 에 맞춰 줄어들어 50 epoch 순위는 예측 불가
- 8% 노이즈에서 ④ 와 ③ 차이는 114장 중 4장뿐 → "④ 가 노이즈에 더 강하다" 고 말할 수 없음

**다음 단계**
1. 학습 없이 노이즈 진단 보강: ③·④ 로 같은 웨이퍼 짝비교, 0~16%, 합성선, die 수 구간, none 오탐
2. 그 결과로 50 epoch 본 실험 결정: 성능이 목적이면 ③, 교수님 질문 ("노이즈가 효과 있나") 이면 ④

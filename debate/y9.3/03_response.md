# 03. 응답 — y9.3 수정 계획 — Claude (2026-11-24)

Codex 판정 "수정 후 진행" (02). C1~C6 모두 수용, 아래처럼 고침.

## 가설 (C6 반영, 좁힘)
"원본 격자 절대 길이 (die) 로 가중한 Frangi 채널이 y9.2 Frangi 채널의 짧은 선 오탐 (none→Scratch) 을 줄이면서 Scratch 검출을 유지하는가." 라벨 규칙이 크기와 무관하다는 주장은 하지 않음 (10~11 die 비율 2.4 / 8.9 / 10.3% 처럼 크기군 차 있음). 길이 분석에 val 을 이미 썼으므로 val 판정은 후보 선별용, 최종 판정은 모든 설계 고정 후 test (WaFixMatch 재현값 대비 기존 기준).

## 채널 정의 고정 (C1)
- 원본 die 격자 (> 96 은 LSWMD.pkl 원본, y9.2 캐시와 같은 경로) 에서:
  - 선 성분 = 불량 die 8-연결 성분 중 불량 die ≥ 3 이고 길쭉함 (주/부 표준편차 비) ≥ 3 인 것. L = 주축 투영 범위 + 1 (die) — `line_length_rule.py` 와 동일.
  - 그 외 성분 (단일점, 2개, 둥근 덩어리) 은 g = 0.
  - g(L) = min(L, 30) / 30 (30 = 포화점).
  - 각 die 의 가중치 = 거리 ≤ 2 die 안의 가장 가까운 불량 die 가 속한 성분의 g (그보다 멀면 0). 채널 = V · 가중치.
- 0단계에서 이 정의 그대로 5% 학습 집계 (길이 구간별 Scratch 비율, 점수 분포) 를 다시 냄.
- 후보 2 (끊긴 선 대비, C2): 성분을 Frangi 능선 {V ≥ τ} 의 8-연결 성분으로 (길쭉함 조건 같음). τ ∈ {0.2, 0.3} 로 미리 고정. 후보 1 이 끊긴 선 기준을 통과하면 후보 2 는 안 봄.

## 0단계 (학습 없음, test 안 씀) — 기준 미리 고정 (C2, C3)
1. 합성 (96 리사이즈 + uint8 후 값): 길이 5 / 10 / 20 / 30 die, 두께 1·2, 각도 0·30·45·90, 웨이퍼 지름 30·45·70 die, 배경 무작위 불량 0 / 5 / 10%, 끊긴 20 die 선 (4 die 마다 1 die 틈).
   - 기준 a: 같은 조건에서 채널 최댓값이 길이에 단조 증가 (중앙값 기준)
   - 기준 b: 배경 불량만 있는 맵의 최댓값 중앙값 < 0.1
   - 기준 c: 끊긴 20 die 선 최댓값 ≥ 연속 20 die 선의 0.5 배 (중앙값)
2. 5% 라벨 학습 세트: 웨이퍼 점수 max(V), max(g), max(V·g) 각각의 AP (Scratch 대 none, Scratch 대 나머지 전체). 기준 d: AP(V·g) > AP(V) (Scratch 대 나머지). 10 die 미만 학습 Scratch (11장) 의 점수 변화 그림으로 확인. 후보 2 를 보면 τ 선택 AP 는 탐색 결과로 기록.
3. 진단 (기준 아님): y9.2a val 오탐에서 Frangi 최댓값을 만든 성분의 원본 길이 (die) 분포. y9.2a 체크포인트에 합성 선과 val none 오탐을 채널 V 대신 V·g 로 넣었을 때 Scratch 확률 변화 (재학습 성능 추정 아님, 감쇠 방향만).
- a~d 중 하나라도 실패하면 학습 안 하고 보고.

## 1단계 (C3, C4, C5)
- 조건: y9.2 1단계와 동일 — seed 0·1·2, ver8 인코더 `masklat8_e50.pt`, v3_nopl, ft30 × 3라운드 = 90 epoch, val macro 로 best.pt, no_test, 같은 라벨 인덱스·SSL 표본.
- 메서드: **y9.3a** = 길이 가중 채널, **y9.3b** = 진폭만 맞춘 k·V (k = 5% 학습 세트에서 mean(V·g)/mean(V), 불량 die 위 평균; C3 대조군). 대조: y9.2a (V), y9.2b (0 채널) 재사용.
- 코드: `args.frangi` 에 "length", "scaled" 모드 추가, 각자 별도 캐시 `~/wafer_cache/y9.3/` (y9.2 캐시 안 건드림). 로더는 "frangi"/"length"/"scaled" 에서 표를 읽고 "zero" 만 0 채널 — 첫 학습 전 assert 로 표가 실제로 읽히는지, 인덱스가 라벨 ∪ seed 0·1·2 SSL 표본을 덮는지 확인.
- 판정 (val, y9.3a − y9.2a, 사후 평가, 실행 전 고정):
  1. macro 평균 차 ≥ +0.005 이고 3 seed 모두 > 0
  2. none→Scratch 세 seed 합계 20% 이상 감소 (y9.2a 156 → 125 이하)
  3. Scratch F1 평균 차 ≥ −0.03, Loc→Scratch 합계 증가 20% 이내
  4. 소수 5개 각각 평균 F1 차 ≥ −0.03, die<1200 Scratch 재현 평균 차 ≥ −0.05
  - y9.3a 가 y9.3b 보다도 1·2 에서 낫지 않으면 "길이 정보" 효과로 주장 안 함.
- 함께 보고: seed 별 짝 차이, 오탐 해소·신규 건수, Scratch AP, 같은 Scratch 재현율에서 none 오탐 수 (y9.2a 의 재현율에 맞춘 임계), 길이·크기 구간별 분모와 재현율.
- 비용: 캐시 2종 약 70분, fine-tune 6회 약 1.5시간, 평가 약 15분.

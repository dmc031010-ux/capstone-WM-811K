# 01. 제안 — y9.3: Frangi 채널에 "선 길이 (die)" 를 담기 — Claude (2026-11-24)

## 1. 배경 (y9.2 에서 이어짐, 근거 파일은 `debate/y9.2/07_final.md`, `runs/y9.2_step1/`)
- y9.2 1단계 (ver8 인코더 + fine-tune 만, 2번째 입력 채널 = Frangi vesselness) 는 seed 0·1·2 val 에서 0 채널 대조군 (y9.2b) 대비 macro +0.024, Scratch F1 +0.143 (평균), die<1200 Scratch 재현 +0.284 로 미리 정한 규칙 ② 통과.
- 남은 문제 ① **짧은 직선 조각 오탐.** Frangi 모델의 none→Scratch 오탐은 불량 양은 정상과 같고, 흩어진 불량 사이에 짧은 직선 조각이 있는 웨이퍼 (`fp_none.txt`: Frangi 최댓값 0.70 대 0.55, 가장 큰 덩어리 길이 26 대 16 px). 오탐 Scratch 확률 중앙값 0.83~0.93 → 모델이 "밝은 Frangi 줄 = Scratch" 지름길을 학습한 것으로 봄.
- 남은 문제 ② **라벨은 절대 길이 (die) 기준.** 5% 라벨 학습 + val 에서 가장 긴 선 모양 불량 덩어리 길이 (원본 격자, die) 별 Scratch 비율: 8~9 die 1~2%, 10~11 die 6~9%, 12~14 die 14~17%, 15~19 die 24~33%, 20+ die 29~100% (`line_length_rule.txt`). 웨이퍼 크기 3그룹의 곡선이 절대 길이에서는 겹치고 (그룹 간 차 0.006) 지름 대비 상대 길이에서는 어긋남 (0.039). 로지스틱 로그 손실 절대 0.0274 < 상대 0.0342, (log 길이, log 지름) 동시 투입 시 지름 계수 +1.42 (`line_length_rel.txt`).
- 모델 입력은 96×96 으로 늘린 맵이라 die 수는 블록 크기로만 간접 표현. Frangi 도 길이 정보를 주지 않음 (짧은 선도 긴 선과 같은 밝기). ver8.1 (분류기 직전 크기 임베딩) 은 val Scratch 0.463 / 0.431 로 ver8 (0.446 / 0.429) 과 같았는데, 선형 분류기에 크기를 이어 붙이는 구조는 "길이 × 크기" 상호작용을 표현 못 함.

## 2. 가설
Frangi 채널의 각 선 픽셀에 "그 선이 원본 격자에서 die 몇 개 길이인지" 를 곱해 넣으면, (1) 10 die 안팎 짧은 조각의 신호가 약해져 none→Scratch 오탐이 줄고, (2) 96 리사이즈 뒤에도 die 기준 길이가 보존되어 웨이퍼 크기와 무관한 판단이 쉬워진다. Scratch 재현은 크게 잃지 않는다.

## 3. 채널 정의 (원본 die 격자에서 계산, 그 뒤는 y9.2 와 동일하게 nearest 96 확대, uint8)
- V = y9.2 Frangi (σ 1·2·3 die, β 0.5, c 전역 고정, 변경 없음).
- 선 조각 = 원본 격자의 불량 die 8-연결 덩어리. 덩어리 길이 L = 주성분 축 투영 범위 (die) — 라벨 분석 (`line_length_rule.py`) 과 같은 측정.
- 채널 = V(x) · g(L(x)), g(L) = min(L, 30) / 30. 불량이 아닌 die 의 V (선 바로 옆 응답) 는 가장 가까운 불량 덩어리의 L 을 씀 (거리 변환 index).
  - 30 은 5% 학습 라벨에서 30 die 이상이면 Scratch 비율 1.0 (5/5) 인 데서 잡음. 임계 (10~15) 를 손으로 넣지 않고 단조 증가 함수만 줘서 판정은 모델이 배우게 함.
- 2채널 구조 그대로 (채널 1 = 원본 맵, 채널 2 = 길이 가중 Frangi). y9.2a 와는 채널 2 의 내용만 다름 → y9.2a/y9.2b 결과를 대조로 재사용.

## 4. 우려 (토론용)
- **끊긴 Scratch.** 실제 Scratch 는 중간이 끊긴 경우가 많아 덩어리 단위 길이가 짧게 잡힘 (학습 Scratch 의 25% 가 10 die 미만). 1 die 틈 이어붙임 (binary closing) 은 흩어진 불량끼리 붙어 측정이 망가짐 (`line_length_rule.txt` 이어붙임 표). 대안: 덩어리를 불량 die 가 아니라 Frangi 능선 {V ≥ τ} 의 연결 성분으로 정의 (σ=2·3 의 Gaussian 이 1 die 틈을 메움). τ 를 새로 정해야 함.
- **덩어리 길이 ≠ 선 길이.** 선이 덩어리와 붙으면 길이가 덩어리 크기로 잡힘. 길쭉함 조건을 둘지 (라벨 분석은 길쭉함 ≥ 3 인 덩어리만 셈).
- **손으로 라벨 규칙을 넣는 것에 가까움.** g(L) 이 사실상 "긴 선 = Scratch" 를 입력에 적는 셈. 라벨 노이즈 (짧은 Scratch 라벨) 를 오히려 더 못 맞힐 수 있음.
- **3채널 대안.** 채널 2 = V 그대로, 채널 3 = g(L) 만. 정보 손실은 없지만 y9.2a 와의 비교가 "채널 추가" 로 바뀜.
- 효과 크기: y9.2 의 오탐 차는 seed 별로 엇갈렸음 (b→a 64→56, 31→33, 52→67). 3 seed 로 오탐 감소를 판정할 수 있을지.

## 5. 계획
- **0단계 (학습 없음, test 안 씀).** 
  1) 합성: 같은 웨이퍼에 5 / 10 / 20 / 30 die 직선, 1 die 틈으로 끊긴 20 die 직선, 흩어진 불량만 → 채널 값.
  2) 실제 (5% 라벨 학습 세트만): 웨이퍼별 채널 최댓값으로 Scratch 대 none 을 가르는 AP 를 y9.2 Frangi 최댓값의 AP 와 비교.
  3) y9.2 오탐 예시 (val none 754928, 10 die 막대) 의 채널 값 확인 (값만 보고, 선택에 안 씀).
  통과 기준 (미리 고정): 합성에서 채널이 길이에 단조 증가, 흩어진 불량만 있는 웨이퍼 최댓값 < 0.1, 5% 학습 AP (길이 가중) > AP (Frangi). 덩어리 정의 (불량 die vs Frangi 능선) 는 2) 의 학습 AP 로만 고름.
- **1단계.** y9.2 1단계와 같은 조건 (ver8 인코더 `masklat8_e50.pt`, fine-tune 만, v3_nopl, no_test), seed 0·1·2, 새 메서드 y9.3a. 캐시는 y9.2 와 같은 웨이퍼 집합 (라벨 + seed 0·1·2 SSL 표본).
  판정 (val, y9.3a − y9.2a, 사후 평가 값, 미리 고정):
  1. 평균 macro 차 > 0 이고 3 seed 모두 > 0
  2. 소수 5개 각각 평균 F1 차 ≥ −0.03
  3. none→Scratch 오탐 평균 감소
  4. die<1200 Scratch 재현 평균 차 ≥ −0.05
- 비용: 캐시 약 35분, fine-tune 3회 약 45분, 평가 약 10분.
- test 는 모든 결정 후에만. 기존 결과 폴더·메서드 동작은 바꾸지 않음.

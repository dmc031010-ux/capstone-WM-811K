## 수정한 계획
0. **Frangi 검증 (학습 없음):** 직접 구현, 사양 4번 검증 5항목 + 위 C2·C6 점검. 통과 수치 기준은 검증 전에 고정: (1) 1/2/3 die 선의 선 중심부 최종 응답이 서로 2배 이상 차이 나지 않음, (2) 3×3 덩어리 중심부 응답 < 선 중심부의 절반, (3) 경계 가짜 응답 (불량 없는 웨이퍼의 최댓값) < 0.05, NaN/inf 0. 링은 값만 보고.
1. **싼 비교 먼저 (Codex 대안, fine-tune 만):** 기존 ver8 SSL 인코더 (`masklat8_e50.pt`, seed 0·1) 의 conv1 을 2채널로 늘리고 새 채널 가중치는 0 초기화. 조건 (a) 두 번째 채널 = Frangi, (b) 두 번째 채널 = 0 (같은 구조 대조). seed 당 조건당 약 15~20분 → 총 약 1.5시간. SSL 마스킹 누출 (C3) 문제가 없음.
2. 1에서 val 기준을 넘으면 (seed 0·1 둘 다 (a) − (b) 의 val macro > 0, 소수 5개 중 −0.03 넘는 하락 없음, die 적은 Scratch 재현율 상승) 그때 SSL 포함 y9.2 (사양 원안) 진행 여부를 다시 결정.

# y9.2 Frangi 선 강조 채널

> 이름은 **y9.2** (yeeun 브랜치 실험 이름). ver9.x 는 main 에 PR 로 합칠 때만 씀. 작성 2026-11-24, 수치는 모두 val (test 는 아직 안 봄).

## 1. 왜 했나

- 라벨 5% 에서 가장 약한 클래스가 **Scratch**: val F1 0.43~0.45, 재현율 0.4~0.5.
- 놓친 Scratch 는 대부분 **none (정상)** 으로 판정됨. 특히 die 수가 적은 웨이퍼에서.
- 같은 웨이퍼 배경에 같은 선을 그리되 굵기만 1 die → 2 die 로 바꾸면 Scratch 확률이 0.89 → 0.11 로 떨어짐 (seed 0). 모델이 "선 모양" 보다 "1칸짜리 가는 선" 이라는 특정 패턴에 기대는 것으로 봄.
- 가설: "이 위치가 선 모양인지" 를 굵기와 상관없이 알려주는 정보를 입력에 직접 넣으면, Scratch (선) 와 Loc (덩어리) 를 구분하기 쉬워질 것이다.

## 2. 무엇인가

- **Frangi vesselness**: 의료 영상에서 혈관 (가늘고 긴 구조) 을 찾는 고전 필터 (Frangi et al., 1998). 각 위치가 "한 방향으로만 길쭉한가" 를 0~1 점수로 줌. 여러 크기 (σ) 를 써서 굵기가 달라도 비슷한 점수가 나오게 만든 필터.
- 적용 방식
  - 웨이퍼의 원래 die 격자에서 불량 die 만 1 로 둔 맵에 적용.
  - σ = 1·2·3 die → 1~3 die 굵기의 선을 모두 잡도록.
  - 결과를 96×96 으로 키워 기존 웨이퍼맵 옆에 **두 번째 입력 채널**로 붙임.
- 바꾼 것은 입력뿐. 모델·손실·샘플링은 ver8 과 같고, 첫 conv 층만 2채널. 새 채널 가중치는 0 으로 시작해서 학습 시작 시점 출력이 ver8 과 똑같음.
- 학습 전 합성 검증 (통과 기준은 미리 고정, 모두 통과)

| 항목 | 값 | 기준 |
|---|---|---|
| 1·2·3 die 선 응답의 최대/최소 비율 | 1.85 | < 2 |
| 3×3 덩어리 중심 응답 | 0.12 | < 선 응답의 절반 |
| 불량 없는 웨이퍼 최댓값 | 0 | < 0.05 |

- 알려진 한계: 덩어리 가장자리, 링, 웨이퍼 테두리 쪽 불량에도 어느 정도 반응함.

## 3. 지금까지 결과 (1단계)

사전학습은 ver8 인코더 그대로 쓰고 fine-tune 만 다시 함. 같은 구조에 두 번째 채널을 0 으로 채운 대조군 (b) 과 Frangi 채널 (a) 비교.

| seed | macro F1 | Scratch F1 | die 적은 웨이퍼 Scratch 재현율 |
|---|---|---|---|
| 0 | 0.815 → **0.832** | 0.41 → **0.56** | 0.28 → **0.62** |
| 1 | 0.797 → **0.825** | 0.44 → **0.57** | 0.34 → **0.51** |

- Scratch 는 두 seed 모두 확실히 좋아짐. 0 채널 대조군은 ver8 과 거의 같음 → 이득은 구조 변경이 아니라 Frangi 정보에서 옴.
- 걸리는 점 ① seed 0 에서 Random F1 이 0.034 떨어져, 미리 정한 기준 (소수 클래스 하락 0.03 이내) 을 아주 약간 넘음.
- 걸리는 점 ② 처음 노린 "굵기에 둔감해지기" 는 이뤄지지 않음. 1 die 선 점수는 올랐지만 3 die 선은 여전히 Scratch 로 못 봄 (확률 0.00~0.01). Codex 리뷰에서 지적받아 해석을 정정함.

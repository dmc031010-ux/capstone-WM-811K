# 01. 제안 — y9.2: ver8 + Frangi vesselness 입력 채널 (A/B 최소 비교) — 사용자 사양, Claude 정리 (2026-11-23)

(이전 y9.2 "B 제한판" 은 실행하지 않고 `debate/y9.2_B_dropped/` 로 옮김. 학습 대상 3장뿐이라 중단.)

## 1. 배경과 가설 (사용자 사양)
- 목표: 라벨 5% 에서 test macro-F1 > WaFixMatch 재현값 0.795, 소수 5개 클래스 각각 재현값 대비 −0.03 이내.
- 관찰: Scratch F1 0.37~0.52, 재현율 0.37~0.51. 큰 웨이퍼의 원래 배경에서 같은 선을 1 die → 2 die 두께로 바꾸면 평균 Scratch 확률 seed 0 0.888 → 0.111, seed 1 0.847 → 0.027 (`runs/hough_eda/fewdie_test.txt`; 0.910 은 배경을 지운 1 die 조건. Codex C6 로 정정). 놓친 Scratch 는 인코더 특징부터 none/Loc 쪽.
- 가설: 선 모양을 scale 무관하게 강조하는 Frangi vesselness (Frangi et al. 1998, 식 14·15) 를 추가 입력 채널로 주면 굵기 민감성이 줄고 Loc (덩어리) 와 Scratch (선) 구분이 쉬워진다.
- 입력만 바꿈. 모델 구조·손실·샘플링은 ver8 과 동일.

## 2. 구현 계획
- 채널: 불량 지시 이진 맵 (웨이퍼 밖 0, 정상 0, 불량 1) 에 2D vesselness. 밝은 구조만 (λ2 < 0), β = 0.5, c = 이미지별 Hessian norm 최댓값의 절반 또는 고정값, scale-normalized (σ² 곱). 웨이퍼 밖은 0 으로 마스킹, 경계 constant 0.
- scale: die 단위 σ ∈ {1, 2, 3}. 원본 격자가 96 이하인 웨이퍼 (811k 중 776k) 는 원본 격자에서 계산 후 캐시와 같은 nearest 로 96 확대. 96 초과 (35k, 라벨 데이터의 약 0.6%) 는 96px 에서 σ_px = σ_die × 96 / max(H, W).
- 정규화: [0,1] 로 하나의 방식 (이미지별 vs 전역 고정) 을 검증 단계에서 정해 보고.
- 캐시: 1회 계산 → uint8 memmap (args.cache 아래). 범위는 라벨 데이터 + 사전학습 표본.
- ver7.3 재사용 범위: 2채널 conv1, 사전학습에서 두 채널에 같은 마스크, CLI 분기. 단 ver7.3 은 "회전 → 채널 계산" 을 모델 안에서 하므로 die 단위 σ 를 못 씀 → `ds.fetch` 가 (원본, Frangi) 2채널을 돌려주게 바꾸고, 회전은 기존 `A.rotate` 가 두 채널에 같은 변환 (nearest) 을 적용.
- 계산: skimage.filters.frangi (미설치 → 설치 후 인자 의미 확인) 또는 2×2 Hessian 고유값 직접 구현 (약 30줄).
- 학습 중 test 평가는 끄고 최종 체크포인트만 test 보고.

## 3. 학습 전 검증 (하나라도 이상하면 학습 안 함)
1) 합성 1/2/3 die 선: σ 별·최종 응답이 굵기별로 크게 무너지지 않는지
2) 3×3 덩어리 (Loc): 선보다 확실히 낮은지
3) 링 (Edge-Ring/Donut): 응답 크기 (Scratch 와 혼동 가능성)
4) 웨이퍼 경계 가짜 응답, NaN/inf 없음
5) 실제 WM-811K 클래스별 평균 응답 분포 (Scratch, Loc, none, Edge-Ring)

## 4. 실험
- ver8 (기준, seed 0·1 결과 재사용) vs y9.2. 라벨 5%, split_seed 0. 우선 seed 0·1 (y9.2 사전학습 2회, 약 14시간; GPU 전력 제한 상태), 이후 2~4 여부 결정.
- 지표: test macro-F1, 클래스별 F1·재현율, 소수 5개 하한, Scratch 대 나머지 PR-AUC, 얼린 인코더 선형 분리, 굵기 조작 실험 (기존 스크립트).
- σ·정규화를 바꿔야 하면 val 로만 고르고 모두 기록.

## 5. Claude 가 보는 우려 (토론용)
- **y9.1 진단과의 관계:** 레이어별 probe 에서 Scratch 정보는 이미 인코더 안에 충분함 (val probe AUC 0.97~0.98). die 적은 웨이퍼도 layer4 에서 거의 따라잡음. 가장 큰 손실은 특징 → 최종 출력, 판정층 교체로는 안 풀림 → 라벨 예시 부족 가설. 입력 채널이 이 병목을 푸는지 불분명.
- **선행 실패:** ver7.3 (입력에 불량 3×3 팽창 채널 추가) test 0.803. 입력 채널 추가 방식이 이미 한 번 이득이 없었음 (다만 팽창은 선을 굵게 하고 Frangi 는 선을 강조한다는 차이).
- **배경 잡음:** 실제 Scratch 웨이퍼는 선 외 불량 die 가 3~9%. 고립된 1 die 불량은 λ1≈λ2 → R_B=1 → exp(−2)≈0.14 배로 줄지만 0 이 아님. die 2개짜리 짧은 조각은 선으로 응답. 흩어진 불량이 많은 웨이퍼에서 "가짜 선" 이 생길 수 있음.
- **굵기 민감성의 원인:** 0.90 → 0.11 은 합성선 두께 조작. 1 die vs 2 die 의 차이가 Frangi 다중 scale 로 정말 사라지는지는 검증 1) 로만 확인 가능. 또 원인이 "선 두께" 가 아니라 "die 적은 웨이퍼의 해상도·배경 비율" 일 수도 있음.
- **비용:** seed 당 사전학습 약 7시간. 2 seed 로는 seed 간 차 (y9 test 0.831 / 0.783) 보다 작은 효과는 판단 불가.
